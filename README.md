# 🍽 Ресторан «Кухня»

Сайт ресторана «Кухня» — это многостраничный веб-сайт с меню блюд, информацией о ресторане, формой бронирования столиков и галереей.  
Проект выполнен на **HTML + CSS + JavaScript** и не требует серверной части.

---

## 📌 Назначение проекта

- Представление ресторана в интернете  
- Ознакомление гостей с меню и атмосферой  
- Бронирование столиков  
- Повышение узнаваемости бренда
